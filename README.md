## 🚀 Projetos

### 💼 StudioDesk

Sistema web de CRM e Kanban para organizar clientes, projetos, tarefas e fluxos de trabalho de agências criativas.

- Desenvolvimento colaborativo de uma aplicação web.
- Interface com React e TypeScript.
- Banco de dados e serviços com Supabase.
- Versionamento e colaboração pelo GitHub.

🔗 Acessar repositório do StudioDesk(https://github.com/enzofernandopaulin/studiodesk)

### 🧠 NeuroGuia

Projeto colaborativo de tecnologia educacional com foco em acessibilidade e personalização para estudantes neurodivergentes.

- Recursos de apoio à rotina e às atividades.
- Exploração de recursos visuais e pictogramas.
- Desenvolvimento de funcionalidades voltadas à acessibilidade.

🔒 Repositório privado, com acesso condicionado às permissões concedidas.
